## How To Use

1. Select the closest recipe by page type.
2. Keep section order and responsive strategy.
3. Replace placeholder content and data bindings.
4. Validate with `references/page-layout-playbook.md`.
5. Optionally generate scaffold automatically via:
   `scripts/generate_page_scaffold.py`.
