# Scope Contract

This skill covers:

- SF5 architecture and layer boundaries
- source sync and source-backed inventory
- top-level routing from task to scenario, recipe, and playbooks
- page/component/block scaffolding
- working-set generation and upstream snippet extraction
- strict validation, regression fixtures, and local verification
- backend guidance only at planning level for Bitrix and Laravel

This skill does not cover:

- full backend implementation inside Bitrix or Laravel
- arbitrary product management workflows outside SF5 delivery
- generic repository automation that is not tied to this skill

Default work surfaces:

- `source-truth`
- `routing`
- `recipes-and-scaffolds`
- `working-set`
- `validation`
- `docs-and-learning`
